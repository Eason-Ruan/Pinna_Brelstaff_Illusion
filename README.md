# Pinna-Brelstaff Illusion Generator

This is a Python tool for generating the Pinna-Brelstaff visual illusion. This illusion produces a peculiar visual perception when rotated, causing stationary concentric rings to appear distorted during rotation.

## Features

- Generates visual illusions based on the Pinna-Brelstaff principle
- Supports customizable parameters (number of rings, segments, inner and outer radii, etc.)
- Provides gradient fill options
- High-quality image export functionality

## Usage

```python
import matplotlib.pyplot as plt
from pinna_brelstaff_illusion import create_pinna_brelstaff_illusion

# Create a basic Pinna-Brelstaff illusion image
fig = create_pinna_brelstaff_illusion(
    inner_radius=2,
    outer_radius=2.5,
    inner_polygon_gradient=False
)

# Save the image
plt.savefig('pinna_brelstaff_illusion.png', dpi=300, bbox_inches='tight')

# Display the image
plt.show()
```

## Parameter Description

- `num_rings`: Number of rings (default 2)
- `num_segments`: Number of segments per ring (default 30)
- `inner_radius`: Radius of the innermost ring (default 3.5)
- `outer_radius`: Radius of the outermost ring (default 4.0)
- `segment_width`: Width of each segment (in degrees) (default 5)
- `segment_tilt`: Tilt angle of segments (in degrees) (default 15)
- `gradient_colors`: Colors for gradient fill, in list form (default ["#000000", "#808080"])
- `inner_polygon_gradient`: Whether to use gradient fill inside individual polygons (default False)

## Principle of the Pinna-Brelstaff Illusion

The Pinna-Brelstaff illusion is a dynamic visual illusion discovered by Pinna and Brelstaff. When an observer approaches or moves away from a pattern of concentric rings composed of tilted lines, the stationary pattern appears to rotate. This phenomenon is related to how the human visual system processes motion information.

By rotating the image generated by this project, you will be able to observe this fascinating visual effect.

## Illusion Principle

The Pinna-Brelstaff illusion is a dynamic visual illusion that produces motion perception through static images. When an observer approaches or moves away from the image, the brain misinterprets radial scaling motion as rotational motion. This effect is caused by the arrangement of tilted line segments in a specific pattern.
